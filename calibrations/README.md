# Calibration registry

One JSON file per `site_id` (e.g. `AuburnU.json`), each containing every `camera_id` calibrated at that site. Generated by `homography_middleware.py calibrate-from-points` (or `calibrate`), keyed by the permanent `site_id`/`camera_id` pair described in the main README.

`AuburnU.json` is a real worked example: an actual calibration for a public street-corner webcam at Auburn University (Toomer's Corner), fit from 6 real GPS/pixel point pairs (mean reprojection error 0.75m). It's included so you can see exactly what a real calibration file looks like -- copy its structure, don't reuse its coordinates for a different physical camera.
